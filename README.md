# TP1 - Todo-list MVC et MVVM

Objectif : ajouter un filtre « Toutes / Faites / À faire » à la Todo-list en MVC, puis transformer la même application en MVVM et tester le ViewModel sans navigateur.

## Démarrage

Prérequis : Node.js 20 ou supérieur.

```sh
node --test
```

## Organisation

- `mvc/` : application de départ et évolution MVC.
- `mvvm/` : transformation de la même Todo-list en MVVM.

Le comparatif MVC/MVVM sera complété à la dernière étape du TP.
